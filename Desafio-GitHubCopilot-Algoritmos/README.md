## 🎯 Sobre o Projeto

Este repositório serve como um diário de estudos e uma coleção de soluções para três desafios de programação (Data Structures & Algorithms). O objetivo é praticar a linguagem Python, aprimorar a lógica de programação e explorar a eficiência do **GitHub Copilot** como uma ferramenta de auxílio ao desenvolvedor ("pair programmer").

## 🛠️ Ferramentas e Tecnologias

* **[Python 3](https://www.python.org/)**: A linguagem principal utilizada para todas as soluções.
* **[GitHub Copilot](https://github.com/features/copilot)**: Utilizado como assistente de IA para sugerir blocos de código, otimizar soluções, gerar testes e explicar trechos complexos.
* **[VS Code](https://code.visualstudio.com/)**: Editor de código principal.

## 🚀 Como Utilizar

Você pode clonar este repositório para testar as soluções localmente.

```bash
# Clone este repositório
$ git clone [https://github.com/Lev-TheDev/DioProjetos.git](https://github.com/Lev-TheDev/DioProjetos.git)

$ cd Desafio-GitHubCopilot-Algoritmos
```

## 🤖 Nota sobre o Uso do Copilot
O GitHub Copilot foi usado ativamente neste projeto, mas não como um "resolvedor automático". Ele atuou como um assistente para:

Gerar boilerplate (código repetitivo).

Sugerir diferentes abordagens algorítmicas.

Auxiliar na escrita de testes unitários.

Refatorar e limpar o código.

Disclaimer: Todas as soluções foram revisadas, entendidas e, quando necessário, corrigidas manualmente. O Copilot é uma ferramenta de produtividade, e não um substituto para o entendimento fundamental da lógica de programação.

## 🤝 Como Contribuir
Sinta-se à vontade para contribuir! Se você tem uma solução mais otimizada para um problema existente ou quer adicionar um novo desafio, siga os passos:

Faça um Fork deste repositório.

Crie uma Branch para sua modificação (git checkout -b feat/solucao-nova).

Faça o Commit de suas mudanças (git commit -m 'Adiciona solução para o desafio X').

Abra um Pull Request.
